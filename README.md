# Astha (আস্থা) — Live Web Application

**Astha (আস্থা)** is a voice-first, bilingual (Bangla & English) AI visual companion designed for blind and visually impaired individuals.

## 🌐 Live Web App
Open the app directly in your browser:
### 👉 [https://mysunatislam.github.io/astha-live/](https://mysunatislam.github.io/astha-live/)

---

## ✨ Features
- **Real-Time Scene Understanding**: Instant object detection and scene description in natural Bangla and English.
- **Hands-Free Conversational Voice**: Continuous listening with wake word `"Astha, ..."` or tap-to-speak.
- **Automatic Safety Guardian**: High-speed passive detection for stairs, sudden drop-offs, fast-approaching bodies, and vehicles with low false-alarm filtering.
- **Smart Room Calibration & Passive Item Memory**: Remembers calibrated rooms and tracks objects (wallet, keys, chargers, medicine) without requiring manual data entry.
- **High-Contrast Clinical UI**: Accessibility-first color modes (Navy-Cyan, Monochrome, Clinical Yellow) optimized for low vision and photophobia.
- **PWA & Offline App-Shell Support**: Can be installed on Android, iOS, or Desktop as a standalone web application.
